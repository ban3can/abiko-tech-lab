# Abiko Tech Lab Landing Page

Abiko Tech LabのGitHub Pages向けランディングページです。静的なHTML/CSSだけで構成しているため、追加のビルド手順はありません。

## Preview

`index.html` をブラウザで開くと確認できます。

## Publish on GitHub Pages

1. GitHubにこのリポジトリを作成してpushします。
2. GitHubの `Settings` > `Pages` を開きます。
3. `Build and deployment` の `Source` を `Deploy from a branch` にします。
4. `Branch` を `main`、フォルダを `/ (root)` にして保存します。

数分後にGitHub PagesのURLで公開されます。
