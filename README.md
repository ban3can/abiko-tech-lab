# Abiko Tech Lab

我孫子を拠点に、教育・環境・地域課題に向き合う小さな実験室「Abiko Tech Lab」のランディングページです。

水辺の森にある小さな実験小屋のような、自然豊かで柔らかい印象を目指しています。静的なHTML/CSSだけで構成しているため、追加のビルド手順はありません。

## Site

https://ban3can.github.io/abiko-tech-lab/

## Contents

- Hero: 我孫子から、テクノロジーで地域を育てる。
- About: Abiko Tech Labの紹介
- Projects: ECOcoro / 子ども向けIT学習 / 地域データ活用
- Mission: 地域の課題を、学びとテクノロジーで解決する。
- Contact: GitHub / X / メール

## Preview

`index.html` をブラウザで開くとローカルで確認できます。

## Files

- `index.html`: ページ本文、メタ情報、リンク
- `styles.css`: レイアウト、配色、レスポンシブ対応
- `assets/hero-lakeside-lab.png`: ヒーロー画像

## Publish

GitHub Pagesは `main` ブランチのルートから公開します。変更を反映するときは、コミットして `main` にpushしてください。

## Update

- 本文は `index.html` を編集します。
- デザインは `styles.css` を編集します。
- ヒーロー画像は `assets/hero-lakeside-lab.png` を差し替えます。
